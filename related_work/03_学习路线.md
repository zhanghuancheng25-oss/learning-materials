# 从零到能读少轮次 mini-batch RR 论文

当前起点按用户说明设为“没有该方向背景”；线性代数、概率论与凸优化的熟练程度尚未诊断。下面是可调整的阅读顺序，不是已经完成的学习记录，也不要求先学完整个深度学习体系。

## 阶段 A：能写出算法

阅读 [入门](00_入门.md) 第 1–5 节。掌握梯度、有限和、采样索引、epoch / batch / update。运行教学脚本，并手算两样本例子。

验收：能解释 `n=64,b=8,K=20` 为什么是 160 次参数更新、1280 次样本梯度计算；能辨认重新分批与固定批次 RR；能解释有放回的一轮不保证看完所有数据。

## 阶段 B：能读懂一个收敛界

补齐：条件期望、方差、独立性、凸性、光滑性、强凸性、PL 条件、$O/\Omega/\widetilde O$；推导下降引理

$$F(y)\le F(x)+\langle\nabla F(x),y-x\rangle+\frac L2\|y-x\|^2.$$

再读 P03 的算法、Definition 2 与 Theorem 1–3。暂不通读全部非凸附录。

验收：能指出 Theorem 1 对每个 $f_i$ 的强凸要求；能说清常步长的噪声项为什么可能留下误差下限；能说明 RR 为什么不满足通常的条件无偏性。

## 阶段 C：理解“少轮次”在问什么

顺序：P05 → P04 → P08。P05 先读定理和数值构造，P04 学下界的量词，P08 再看 Theorem 1、Corollary 1。

验收：能区分“所有实例都更好”“存在坏实例”“最坏情形上界不更差”；能解释 P05 与 P08 为什么不矛盾；知道少轮次应相对 $n$、$\kappa$ 等参数定义，而不只是固定说 5 轮。

## 阶段 D：进入 mini-batch

顺序：P07 的第 2 节与 Theorem 3.3 → P06 的算法和 Theorem 1 → P10 的固定分批约化。先用单机情形理解，再加机器数 $M$。

验收：把 P06 的 $M,N,B,K$ 与 P07 的 $n,B$ 翻译到统一符号；能推导固定分批 $g_j=(1/b)\sum_{i\in B_j}f_i$；能解释 $F(\mathbb E[x])\ne\mathbb E[F(x)]$；知道有限总体方差公式不能原样套到 RR 的每个动态迭代点。

## 阶段 E：正式复现后再选问题

先复现 P03 或 P05 官方代码中的一个明确图表，再拓展 batch size 或 epoch budget。固定数据、样本梯度次数、调参预算与种子；记录失败案例。

验收：写出“论文配置—本机配置—差异—结果—限制”报告。教学脚本完成不算论文复现完成。候选方向只在 [brainstorm.md](../brainstorm.md) 作为问题记录，不能直接写为创新贡献。

## 今天的第一段任务

只完成阶段 A：读入门第 1–5 节、手算 $\eta=0.1$ 的两样本例子、运行脚本、解释输出图中横轴的工作量。看不懂的词回到入门表格，不急着啃 76 页 P06。

后续需补充的信息：具体“Few-Epoch Mini-batch RR”链接用于确认目标文献；概率论与凸优化掌握程度用于决定阶段 B 深度；研究更偏理论还是应用用于决定阶段 E 的复现对象。它们不影响目前资料库的建立。
