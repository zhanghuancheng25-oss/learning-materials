# P09 · Random Reshuffling is Not Always Better

**位置：反例阅读。避免把很多情形下的优势升级为没有条件的全称命题。**

- 作者：Christopher De Sa；NeurIPS 2020。
- [论文](https://proceedings.neurips.cc/paper_files/paper/2020/file/42299f06ee419aa5d9d07798b56779e2-Paper.pdf)。
- 阅读深度：摘要、§4 步长比较和 §5 普通 SGD 反例机制；未重做矩阵构造证明。PDF 已下载，源码入口未核实。

## 内容

论文构造非交换算术—几何均值相关猜想的反例，并展示 with-replacement 可优于 RR 的优化任务。需要区分前面带平均的算法与 §5 的普通 SGD 反例，不能把前者直接称为普通 SGD 的结论。

同一个学习率策略下比较，与允许两种算法分别调优，是不同问题。论文还给出普通 SGD 中有放回采样渐近更好的特殊构造，说明“每个任务 RR 都赢”不能成立。

## 对实验的要求

既报告相同学习率的机制对照，也给各算法相同调参预算的比较；记录输出是否平均、采样范围与噪声设置。这里不是对“RR 通常有用”的否定，也不表示这些特殊反例的出现频率已经被实测确定。

与 P08 的关系：某函数类上的最坏情形收敛界支配，不等于对每个具体函数逐实例支配。当前无反例数值复现。
