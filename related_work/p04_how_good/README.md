## 结果怎么读

论文针对固定步长方法，在光滑强凸有限和类中构造困难实例。忽略共同的 $G^2/\lambda$ 等因子、并处于未被初始误差截断的范围时，下界含有：

| 方法 | 代表性下界依赖 |
|---|---|
| RR | $\Omega(1/(nK)^2+1/(nK^3))$ |
| SO | $\Omega(1/(nK^2))$ |
| IG | $\Omega(1/K^2)$ |

这些是存在困难实例的**下界**，不是所有数据集会观测到的下降曲线。原定理还包括初始误差截断、参数范围及函数类条件；表格仅用于看结构差别。相匹配的上界部分有一维二次限制，不能外推为一般高维问题已全部解决。

## 对少轮次的意义

在 RR 下界里，$1/(nK^3)$ 与 $1/(n^2K^2)$ 的相对大小随 $K/n$ 改变。仅盯着“$K^{-2}$ 比 $K^{-1}$ 快”会遗漏主导项及样本量影响。进一步看条件数应读 P05。

## 后续复现

选其中一个一维构造，枚举小 $n$ 的排列验证一次 epoch 的精确公式，再增加种子检验经验期望。不要把跑一个随机二次问题称为复现了最坏情形下界。当前未实施。
