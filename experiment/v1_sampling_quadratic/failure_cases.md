# 固定反例配置与限制

没有 NaN / Inf 或实现验收失败。以下保留“不符合简单直觉”的配置，不能从报告中删除：

1. $\kappa=1,b=1,\eta L=0.2$：本次 10 个采样种子，RR 最后点平均误差高于 WR；不做统计显著性或普遍性声明。
2. $\kappa=100,b=1,\eta L=0.2$：RR 的最后点平均误差也高于 WR，说明不能把标题中的理论支配误读为固定配置必胜。
3. $b=n=64$：WR 与四种无放回方法没有完全重合；原因是 WR 允许批内重复，不是程序遗漏。
4. $b=1$：RR 与 rr_fixed 完全重合；二者在此边界确实是同一个采样过程。
5. IG 使用按中心第一坐标排序的输入；这有意保留顺序效应，不代表随机数据顺序的平均表现。
6. 某些种子离散程度较大，均值减标准差为负；标准差不是对数尺度的置信区间。初始图显示不佳，已只调整坐标范围，原图保留。

所有候选学习率均保存。下次比较保持这些配置与种子，若改数据问题族须另起版本。
