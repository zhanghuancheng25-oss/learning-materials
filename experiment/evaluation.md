# 固定测评规范

版本：`rr_quadratic_teaching_v1`。本规范在教学实验首次运行前建立。范围是有限和训练目标的采样机制验证，不是论文图表复现、泛化实验或最优复杂度证明。

## 数据与预算

使用 $n=64,d=2$ 的共同 Hessian 二次分量：$f_i(x)=\tfrac12(x-c_i)^TH(x-c_i)$。$H=\mathrm{diag}(1,\kappa)$，$\kappa\in\{1,100\}$；中心用数据种子 20261117 生成，按第一坐标排序固定输入顺序。排序用于观察 IG 的顺序敏感性，不能据此代表自然数据分布。

最优点 $x_\star=\bar c$，$x_0=x_\star+(3,3)$。精确函数差为 $\tfrac12(x-x_\star)^TH(x-x_\star)$。共享 Hessian 是受控简化，不是 P05 的下界构造。

固定 batch sizes：1、8、64；epochs：20；检查点：1、5、20；采样种子：0–9；学习率：$\eta=c/\kappa$，$c\in\{0.05,0.2,0.8\}$，在全程固定。

每种配置每轮固定消耗 64 次分量梯度，共 1280 次。更新数 $1280/b$。不测 GPU 加速或分布式通信。

## 算法

- `wr`：每次批内样本独立有放回抽取，批间也独立。
- `rr`：每轮重新排列全部样本再切批。
- `so`：只打乱一次，后续重用同一排列及切批。
- `ig`：固定输入顺序。
- `rr_fixed`：固定连续分批，每轮只打乱批次顺序。

在 $b=n$ 时，RR / SO / IG / rr_fixed 都退化为 GD；`wr` 仍允许一批中重复，不能视作 GD。这一点必须在结果解释中保留。

## 指标与可视化

保存全部配置及每个采样种子的逐轮目标差。汇总每个检查点的均值与标准差、最终点误差、全部更新前参数平均后的误差、样本梯度次数和更新次数。

固定展示 $c=0.2$ 的逐轮曲线，横轴为分量梯度数；另给所有候选学习率的最终误差表。可计算各算法相同网格内的最佳平均表现，但明确这只是该合成目标上的 oracle 调参结果，不是测试集结论。不得只保存最好学习率。

同时检查 $\mathbb E[F(x)]-F_\star$ 与 $F(\mathbb E[x])-F_\star$，不能互相替代。

## 实现验收

1. RR / SO / IG / rr_fixed 每轮索引覆盖 0–63 各一次；SO 排列跨轮相同。
2. 数值差分核对解析梯度。
3. $b=n$ 无放回算法与显式 GD 一致。
4. 小总体穷举验证有限总体方差恒等式。
5. 两样本手算例子与数值结果一致。
6. 所有配置无 NaN / Inf，实际更新数与预算一致。

输出到 `experiment/v1_sampling_quadratic/`：`metrics.json`、`trajectories.json`、`convergence.png`、`stepsize_grid.png`、`failure_cases.md`。脚本拒绝覆盖已经存在的结果目录；新实验用新版本目录。只有独立实现缺陷需要修正时，保留旧结果并记明原因。
